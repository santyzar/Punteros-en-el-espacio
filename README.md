# Punteros-en-el-espacio
Clon de Space Invaders en C puro y SDL2. Proyecto integrador para la materia Tópicos de Programación (UNLaM) enfocado en el manejo de memoria dinámica, aritmética de punteros y colisiones.

Como compilar y jugar (CodeBlocks):
  1. Abrir Space_Invaders_SDL.cbp
  2. Build > Rebuild
  3. Run

Si al ejecutar aparece "falta SDL2.dll":
  copiar SDL2\bin\SDL2.dll dentro de la carpeta bin\Debug (o bin\Release),
  junto al ejecutable que genera CodeBlocks.

Controles: A/D o flechas mover - Espacio disparar - P pausa - R reiniciar (al terminar) - Esc o Q salir
